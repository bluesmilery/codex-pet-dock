# 优化 Week Tokens 对齐与详情卡

## Goal

修正底座右侧 `WEEK TOKENS` 指标的垂直对齐，并重新设计点击底座展开的详情卡，使两处 UI 在不改变数据语义和交互方式的前提下更整齐、易读，并与当前主题视觉一致。

## Background

- `DockView` 左列包含标题、主值、重置时间三行，右列只有标题和主值两行；右列当前从顶部排列，因此视觉上没有在底座内垂直居中。
- `DetailPanel` 当前是固定 `230×190` 的七行裸列表，标签没有统一宽度，且背景、字体和强调色不随主题变化，整体更像调试信息面板。
- 当前仓库基线为 `dev@4cc16a2`；根目录未跟踪的 `design/` 属于用户现有内容，本任务不得修改或纳入提交。
- 详情卡现有字段、底座点击展开/收起行为、全屏空间行为和屏幕边缘水平约束应继续保留。
- 首个候选 `e1d62cb` 的真机视觉 QA 判定为 NO-GO：详情卡风格已通过，但右列标题和值整体仍上偏；本轮以用户补充的精确视觉合同替代原“整组居中”要求。

## Requirements

- Delivery Path: L2
- R1：`WEEK LEFT` 与 `WEEK TOKENS` 两个标题必须保持同一顶线；`WEEK TOKENS` 数值在标题下方的剩余可用区域内垂直居中，不再将标题和值作为整体居中，也不得用任意固定像素偏移掩盖问题。
- R2：保持底座外框 `200×48`、左右等宽分栏、现有字段内容、占位符与主题字体语义不变。
- R3：详情卡保留套餐、重置时间、缓存比例、输入、输出、会话数、更新时间和本机估算提示，不改变数据来源或格式化逻辑。
- R4：详情卡采用用户选定的 B 方案：七行紧凑双列表格，标签列左对齐、数值列右对齐并共享稳定列宽；左右文字字号一致，行间距比首个候选更宽，底部单独展示本机估算提示，面板高度贴合内容且底部不得留下大块空白。
- R5：详情卡必须与当前底座保持同一视觉风格，直接复用当前 `ThemeMetrics` 的背景色及透明度、强调色边框、圆角、标签色和字体 token；不得另造独立配色或材质。切换主题时底座和已创建的详情卡同步换肤。
- R6：详情卡默认相对底座水平居中；保持点击底座展开/收起、底座隐藏时关闭、浮动层级、跨 Space/全屏辅助和屏幕边缘水平 clamp 行为，靠近屏幕边缘时仍以不越界为优先。
- R7：先补布局/主题相关的失败测试，再做最小实现；不得读取认证文件、会话正文或修改 TCC/ScreenCaptureKit 行为。
- R8：实现使用现有原生 AppKit 组件和矩形圆角 `NSPanel`；不实现概念图中的气泡尖角，不引入自绘窗口形状、图片或外部资源。

## Acceptance Criteria

- [ ] AC1：自动化测试直接观测到两个标题绘制矩形的顶线一致，且 `WEEK TOKENS` 数值绘制矩形的中点与标题下方剩余可用区域中点一致（允许 AppKit 像素舍入容差）；底座仍为 `200×48`。
- [ ] AC2：详情卡所有既有字段和本机估算提示均可渲染，占位行为不回归。
- [ ] AC3：详情卡七行标签共享稳定左列、数值共享稳定右列并右对齐，左右字号一致；行分隔、增大的行间距与底部提示形成清晰层级，最后内容与底边仅保留设计内边距，不存在大块空白、截断、重叠或超出内容边界。
- [ ] AC4：三种内置主题下，详情卡与底座使用同一组 `ThemeMetrics` 背景（含 alpha）、强调色边框、圆角、标签色和字体 token，切换主题后同步更新。
- [ ] AC5：详情卡在常规位置相对底座水平居中；现有 `.fullScreenAuxiliary` 与屏幕左右边缘 clamp 测试继续通过。
- [ ] AC6：`swift build -c release` 0 warning，`make test` 全绿，独立正式 Review 对冻结 SHA 报告 P0/P1/P2 为 0。
- [ ] AC7：对同一冻结 SHA 生成全新的 `build/candidates/YYYY-MM-DD-HHmmss-<label>-<shortSHA>/PetDock.app`；自动化、静态审查与肉眼/真机未验证项分开报告。

## Out of Scope

- 不更改 WEEK LEFT / WEEK TOKENS 的数据采集、统计口径或刷新节奏。
- 不更改底座跟随、气泡避让、窗口识别、TCC 或 ScreenCaptureKit 行为。
- 不新增字段、设置项、动画、图表或外部资源。
- 不修改或提交根目录现有未跟踪 `design/`。

## Key Decisions

- 用户选择 B 方案（双列表格），不采用摘要区 + 2×2 指标网格。
- 概念图仅用于确认信息层级；生产实现不包含气泡尖角。
- 详情卡的风格来源是当前底座主题，而不是概念图自身的配色或材质。
- 本任务按轻量 L2 处理，以本 PRD 作为规划与验收合同，不新增 `design.md` / `implement.md`。
